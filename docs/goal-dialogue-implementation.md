# 目标对话、分阶段补问与决策记忆：实现说明

更新日期：2026-10-04

## 使用入口

在财富总览“人生目标”输入买车想法，直接在首页继续对话、核对资料、比较和采纳。预算不必先确定。选择“打开买车详情”可进入原详情页；首页、详情页和刷新恢复使用同一份决策记录。明确的买车意图才进入扩展流程，其他或混合目标继续原澄清流程。

旧的未完成目标对话在明确买车意图后可以关联买车草稿，保留原消息和已取得的金额、日期。正式目标仍在采纳时创建。重复进入同一未完成买车决策不会创建新目标。

## 分阶段体验

确认卡依次围绕目标、收支、资金、费用和保护边界展开。每轮规则补问最多两个当前阶段的问题，也可一次补充多项。已读取的资产、负债和收支用于核对，无需重录底账。未参与的资产无需填写可用日期；全款路径无需贷款报价。

确认收入、生活支出和现有还款后即可看到带限定说明的初步现金流结果。资料不全时不强行显示可负担预算。关键费用、资金边界和确认状态仍是正式采纳的前提。

点击“保存并继续”才切换当前确认卡，避免勾选后页面突然跳动。服务端保存已确认进度；编辑中的资料暂存在同一浏览器对应的工作区和决策中，资料版本不匹配时不会用旧缓存覆盖新底账。跨月复盘不会恢复旧月份的实际资金确认。

## 预算、推荐与选择

预算上限明确标为承受边界。意向预算可行时，仍增加低两成预算的确定性对照，展示购车后剩余资金和每月余量；低两成仅为比较示例，不代表车辆推荐或用户一定接受的预算。

采纳摘要展示自备资金来源、购车时间、价格、应急底线和已接受的消费削减。取消常规理由输入。系统记录客观选择和确认事件，原因没有明确说明时保持未知。采纳更低预算或延期方案后，后续维护使用实际选择的预算与时间。

## 偏好及证据

个人画像新增“规划偏好与约束”，买车资料页也可查看当前决策相关记录。包括原话、来源引用、作用范围、软偏好或硬约束、复核条件、时间与版本。支持纠正、确认作用范围及删除。删除立即停用，已采纳快照保留历史证据。

明确表达默认仅用于当前决策且为软偏好。首版可确认的硬规则为“仅全款”和“不动用指定资产”。只有明确确认后才参与计算；其他自由表达可以作为参考，不能隐式排除可行方案。跨目标范围单独由用户勾选确认，不从单次选择推断长期画像。

首版允许不生成 AI 动机推断；不主动给用户贴性格或风险标签。存储和上下文权限区分 INFERENCE，待核实理解只允许在标记清楚的解释上下文中出现，不得改变金额、资金占用、风险等级或生效方案。没有使用模型自报置信度授予权限。

AI 提取只针对当前消息，结构化字段必须有来自该消息的证据摘录。模型名称和提示词版本保存在字段证据中。失效偏好不会通过整段旧聊天重新传给模型；财务历史也不写入普通运行日志。AI 不可用时，明确数字的规则提取与资料卡继续工作。

## 数据变化及上下文

依赖快照分别记录资产、负债、收支画像及其他目标。相关资产余额、归属或调配权限变化时重新核实资金；负债及收支变化时重新核实现金流；其他目标变化时重新核实占款。未受影响的费用确认和偏好保留。当前明确表达与旧硬规则冲突时，旧规则进入待复核，新的正式方案仍需用户确认。

上下文先按工作区、决策、有效状态及用途筛选：

- 新目标澄清只带已确认范围内的相关偏好；不同目标的一次性选择不混入。
- 确定性计算只读取有效、已确认的硬规则及最新底账。
- 比较说明可读取本次软偏好；采纳快照只把实际展示的硬约束与消费取舍记录为已接受条件。
- 月度复盘读取当前生效方案的取舍和最新实际数据，已执行的削减仍不重复计入结余。
- 删除、被替代及待复核的记录停止约束新方案；原生效方案保持不变，直到用户确认调整。

## 验证与试用

2026-10-04 在隔离的临时数据库完成完整回归：35 个测试文件、175 项测试通过。新增覆盖预算未知、阶段问题数量、资料部分确认、初步结果、明确证据、作用域、硬规则权限、删除停用、历史快照、工作区隔离、会话迁移、相关依赖失效以及不同预算取舍。

页面实际操作已验证：首页表达目标 → 分阶段确认 → 预算上限 → 更低预算对照 → 无理由表单采纳 → 个人画像纠正偏好 → 详情页继续 → 刷新恢复同一生效方案。真实底账与模拟案例分开使用。

最终版本再次完成 35 个测试文件、175 项测试的完整回归，生产构建和类型检查通过。新增功能检查无 lint 错误，保留的复杂度警告待后续拆分；页面切换关闭调试侧栏改为在导航事件中执行。现有本地数据库已应用决策记忆迁移，升级前备份位于 `/tmp/ai-wealth-before-memory-20261004.db`。预览使用更新后的生产构建，地址为 `http://127.0.0.1:3000`。
