# 首次启动与跨平台交付

日期：2026-10-17。基础环境：Node.js 22、Python 3（sqlite3 标准库）、Git。

## 用户流程

```sh
npm ci --include=dev
npm run dev
```

启动自动完成环境检查、缺省配置模板、新库初始化、已有库迁移前备份、示例初始化、Web 与两个 worker 启动。API 密钥可自行填写；未配置仍可使用手动流程。`setup` 可提前初始化，`dev:web` 只运行 Web，`start` 使用已构建的生产页面。

首次浏览器访问使用独立演示空间；已有浏览器所选工作区优先。切换个人空间不复制演示资产。初始化复用完整演示，不覆盖用户编辑。

## 实现约束

- 脚本使用当前 Node 进程执行 Prisma、Next、TypeScript 等包的 JS 入口，不直接执行 `.bin` shell 文件。
- 统一检测 `python3`、`python`、`py -3`，支持 `PYTHON_EXECUTABLE`。服务端备份和测试脚本共用该逻辑。
- 产品数据库相对路径统一基于 `prisma`；启动与 Prisma 连接使用相同的绝对路径。支持带空格和中文的路径。
- 迁移前校验完整性与历史；待迁移已有库先备份。失败迁移、未知数据库和较新数据库不自动重置。
- 进程锁避免同一数据库重复启动；旧锁仅在所属进程退出后回收。Windows 退出时使用系统自带 taskkill 关闭子进程树，无需另装命令。
- 日常备份失败只影响备份状态，页面显示提醒和重试入口；恢复／迁移前的保护步骤失败仍停止操作。
- 不读取或复制原项目的密钥和个人数据库。
