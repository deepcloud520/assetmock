## 真实服务验证

1. 资产管家：独立演示工作区，真实模型读取现金、基金、保护资金，运行状态 `COMPLETED`。
2. 长局游戏：真实模型完成购房目标整理、已揭晓事件解释及经过引擎验证的重玩建议；360 月结局完成。
3. 豆包搜索：查询返回成功，购房匹配资料 5 项；无结果／错误仍保持明确标记的预设方案回退。
4. 当前底账的目标整理：首次调用回退到规则表单，未将其计为模型成功；随后对冻结简化底账重试，返回 `source=model`，角色 ID 与确认快照一致。首次失败未记录可判定根因，不能断言为哪一家服务的问题。

真实模型和搜索具有延迟及不稳定性；这次成功不保证每次可用。手动表单、结算与选择无需模型成功，回退有明确来源标识。

## 本机演示步骤

1. 运行 `npm run dev:all`，打开 `http://127.0.0.1:3000`。
2. 点击「进入独立演示空间」，查看五管家、底账及买车／买房目标。
3. 「未来规划→情景推演」查看来源、保护资金排除、简化假设，确认后进入付款方案比较。
4. 推进阶段、处理选择，保存报告，再返回报告列表查看或继续。模型不可用时使用手动方案。
5. 「投资管家→模拟交易→历史回放」使用合成行情；AI 策略实验需单独确认股票池、策略与授权，再手动执行当前回放时点分析。

目前交付为本机单用户应用；匿名会话不是公网账号系统。合成行情只证明流程，不证明投资收益。人工离线 `backup:all` 副本需要自行管理和删除，页面清除操作不替用户销毁这些副本。

## 本次发现并修复

- 初始测试共用数据库、整批测试进程停滞：改为临时迁移数据库和四组限时运行，实际重新执行通过。
- 旧规划测试仍断言已撤下的压力测试入口：改为验证新的嵌入式推演入口。
- 游戏作用域内 CSS 变量未继承：改为 `:scope`，手机端主按钮蓝底白字已检查。
- 离线备份脚本的 CommonJS 导入兼容与旧记录页面类型遗漏：修复后通过针对性验证。
- Git 大包推送多次传输失败：使用 GitHub Git Data API 发布，并逐一校验远端树与提交 SHA 等于本地；没有强制覆盖远端历史。
