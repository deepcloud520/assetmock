启动：先配置 .env.local；新数据库运行 DATABASE_URL=file:./financial-associates.db npm run db:migrate；已有库停服务后运行 npm run db:migrate:safe。npm run dev:all 同时启动 Web 和两个模拟交易 worker。npm run build 后使用 npm run start:all。

模型：管家优先 OPENAI_*，游戏优先 LLM_*，未配置时互相回退，显式配置优先；视觉模型单独配置。豆包搜索继续使用 DOUBAO_SEARCH_API_KEY。
