# 财务人生模拟 MVP：实现与验收记录

更新：2026-10-06。

## 已实现

- 第二步：纯 TypeScript 逐月引擎，按现金收入、必要支出、事件支出、逐笔还款、可选支出、目标投入结算。每次推进停于年末、事件、现金缺口或目标月份。三种策略分别保留 0 / 3 / 6 个月必要支出与月供。逐笔还款不超过余额，目标资金不用于支付日常账单。
- 第三步：代码中的 24 张事件卡、4 条后续链。事件金额由开局基准金额和固定比例生成，发生记录保留解析后的金额。资格、排除、冷却、次数、互斥与持续期均由结构化字段处理。固定种子每年选一个候选月份，合格池含权重为 3 的无事件选项，每年最多一个探索事件，间隔至少 3 个月。
- 第四步：未来规划 → 情景推演默认显示人生模拟；旧版手动单事件压力测试作为次入口。支持示例人生、真实画像、支出与资金口径确认、策略选择、时间轴、事件说明、月账本、结局和重新开局。资金、文字均来自开局或结算结果；不调用 AI 生成金额。
- 本机存档：保存开局、版本、种子、推进次数与时间。恢复时校验后重放，重新得到事件、账本和结局。版本不兼容、非法金额、超长期限或不同工作空间的真实存档不能恢复。底账或选定方案变化时，历史局显示暂停提示。

## 当前产品约定

- 事件是本局假设，权重不是现实概率；不生成医学诊断、婚恋状态或升迁事实。
- 不隐含出售其他资产、借款、透支、投资收益或贷款利息。月供全部减少本金的简化假设在开局说明。
- 当前开局只有汇总的其他资产金额，未提供具体资产类别的暴露数据，事件库暂不安排市场价格冲击，避免错误扣减全部现金或目标资产。
- 方案共享事件脚本的横向比较、多设备存档、历史多局管理仍属于后续产品范围。
