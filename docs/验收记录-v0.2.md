## 真实模型与搜索

使用部署环境原有AIPing配置与豆包搜索Custom Key，密钥未输出、未提交。

`npm run test:live:v2` 已完成：

1. 真实购房检索返回5条匹配资料；模型调用计算工具，得到100万元、30%与50%首付、360个月的方案。
2. 固定失业事件暂停后，模型解释当前事件与六个月试算，返回有效事实引用。
3. 固定经历完成360个月后，引擎验证候选，真实模型选择“改变一次历史职业选择”。

三个环节source均为model。早期测试曾出现工具编排超时和正文包含月份数字的校验失败，未当作通过。已缩短开局编排、限制资料长度，并增加一次解释纠正。额外发现的购房/购车混淆已增加目标一致性校验；明确的求职工资规则纳入事实，禁止模型声称临时工资随机或不稳定。

## 使用与限制

- 主入口为v0.2，购车60月、购房360月。旧存档从/legacy继续，保留自身周期。
- 模型或搜索可能因网络和供应商状态失败，产品显示规则回退，结算不依赖模型。
- 固定物价、零正常投资收益、独立游戏事件，不代表长期现实预测。
- 没有执行生产部署或合并main。本次功能在dev来源分支中按引擎、接口、界面、验收分组提交，通过一个集成PR审核。
