## 1. 产品目标与完成定义

用户用虚拟资金体验 A 股投资，能够自主查看行情、提交买卖委托、管理持仓、理解费用与盈亏，并用真实记录复盘自己的决策。未来投资 Agent 可以通过同一交易服务开展获得授权的自动模拟交易。

首版完成定义：在受支持股票与交易时段内，用户能够完成“创建账户 → 搜索股票 → 买入委托 → 模拟成交 → 持仓估值 → 次一交易日卖出 → 资金与盈亏对账 → 保存复盘”。部分成交、撤单、数据异常和服务重启时，资金及持仓仍一致。

本次文档交付不代表模拟交易已经上线；后续开发按技术文档的批次和验收门槛执行。

## 3. 页面与主流程

### 3.1 页面布局

- **资产与产品**：保留现有真实资产资料、用途分析、产品筛选与管家对话。
- **模拟交易**：固定显示“模拟账户”；账户概况、自选和搜索、个股行情与买卖面板、持仓、当日委托。
- **交易复盘**：账户与日期筛选、收益及费用、历史订单、成交、资金流水、交易理由、复盘笔记和导出。

归档账户可在复盘页查看，模拟与真实持仓不混列、不共用余额。首版管家不从聊天自动提交模拟订单，也不将模拟收益加入总管家的真实财务事实。

### 3.2 用户流程

1. 创建模拟账户，了解初始金额、模拟成交口径和费用配置。
2. 搜索证券，查看板块、报价时间、市场状态、买卖盘口和基础走势，加入自选。
3. 填写方向、限价、数量和可选理由；预览预计金额、费用、可用资金或可卖数量。
4. 确认后服务端再次检查，返回委托编号或明确拒绝原因。预览不锁定行情，不承诺成交。
5. 查看等待、部分成交或全部成交；可撤销剩余数量，已成交部分保留。
6. 在持仓页查看成本、市值、浮盈及可卖日期，按规则卖出。
7. 查看已实现盈亏、完整资金变化和费用，补充复盘笔记。

### 4.1 账户与资金

- 初始资金产生明确的“模拟初始资金”流水，不记为收益。
- 买单冻结最大可能占用的货款及费用；卖单冻结相应可卖数量。冻结不改变现金总余额和总持仓数量。
- 成交按实际金额入账；撤单、到期或终止释放剩余冻结。
- 归档需先结清未成交委托的冻结资源；已有股票作为归档时持仓保留，不虚构平仓。归档后账户停止交易与持续估值，历史末值保留日期和质量。
- 账户不提供真实充值、提现、券商连接或实际交易入口。

### 4.2 行情与证券资料

- 最新报价、盘口、历史走势是不同资料，分别记录时间与来源；证券代码必须包含市场，避免重名代码混淆。
- 日 K 线首版采用不复权价格并标明口径；成交只用当前交易报价。历史走势图不包含未发生的数据。
- 高频关注集合为当前查看、自选、持仓及未完成委托涉及的股票；全市场目录独立同步。
- “3—5 秒轮询”为工程试验参数，不等于已经确认的行情更新频率。交易时段验证后才确定实际刷新配置。
- 获取时间更新、行情时间未更新时，不能显示成新报价。无新鲜数据时保留最后报价供查看，同时禁用撮合。

### 4.3 委托与撮合

- 首版采用简化盘口成交模型：买入参考卖一，卖出参考买一；价格满足限价、有效数量充足并通过规则检查后才能成交。
- 单次成交受可见数量约束；同一账户不能用重复轮询到的同一份报价无限成交。
- 不模拟交易所真实排队位置；对封板、空盘口和不确定状态采取保守处理，不能因最新价触及限价就判定成交。
- 全部成交、部分成交、取消、部分成交后取消、到期、拒绝须可区分；失败重试不产生重复委托或成交。
- 用户撤单与撮合并发时，按服务端提交顺序处理；撤单不撤回已经提交的成交。

### 4.4 A 股交易边界

- 使用交易所交易日历与北京时间；节假日调休工作日不直接当成交易日。
- 按规则控制买入后的可卖日期，展示“可卖”与“持有”的差异；不能简单在买入 24 小时后解锁。
- 申报数量、价格最小变动单位、价格范围、涨跌幅和证券特殊状态按板块及生效版本核实。不能将所有板块都写成“100 股、10%”。
- 连续竞价之外不接收新订单。午间不撮合、支持撤销；收盘集合竞价阶段不撮合，首版模拟撤销规则在界面单独说明；当日收盘后未成交部分到期。
- 费用配置展示佣金、最低佣金及适用税费。券商佣金属于模拟假设，交易所税费规则需有核对来源；首版不在未核实状态下承诺“与实盘费用完全一致”。

### 4.5 盈亏口径

在没有资金追加、公司行为且所有持仓估值有效时：

```text
可用现金 = 现金余额 - 冻结现金
持仓市值 = Σ（持有数量 × 当前估值价）
账户总资产 = 现金余额 + 持仓市值
累计盈亏 = 账户总资产 - 初始模拟资金
累计收益率 = 累计盈亏 / 初始模拟资金
浮动盈亏 = 持仓市值 - 剩余持仓成本
已实现盈亏 = 卖出净收入 - 对应卖出成本
```

买入费用进入持仓成本，卖出费用从卖出收入扣除；汇总累计收益时不能再次减一遍已计入的费用。采用移动加权成本，部分卖出按比例结转成本；最后卖出剩余持仓时结清舍入尾差。

例：初始 100,000 元，买入 1,000 股、每股 10 元，本例买入总费用假定 5 元。现金为 89,995 元、成本为 10,005 元。股价升至 11 元时，市值 11,000 元、总资产 100,995 元、浮盈 995 元；现金仍是 89,995 元。全部卖出时若本例卖出总费用假定 10 元，则最终现金 100,985 元、已实现盈亏 985 元。此处费用仅用于解释算例，不代表市场收费标准。

区间收益用有依据的区间起止估值计算；缺少边界估值时显示可覆盖区间。新增初始资金、冻结与解冻均不能伪装成投资收益。

### 4.6 公司行为与复盘真实性

- 分红、送转、配股、拆并股、退市等会影响股数、成本或估值。首版须具备事件核对与阻断能力；自动全覆盖进入二期。
- 每个交易日前核对持仓及委托涉及证券的状态和公司行为资料。未能核实时暂停相关证券新交易和撮合，可撤单；相关估值及账户收益显示“不完整/待核对”。
- 已识别但无法自动处理的事件进入维护队列。人工根据来源登记可支持的调整，生成独立调整记录及影响说明；不改写原始成交。暂不支持的事件保持暂停，可归档该训练账户。
- 调整或资料更正后的历史报告保留原版本及修订原因。曲线仅展示有证据的估值点，缺失区间不补造平滑收益。

## 5. 异常与服务边界

| 场景 | 用户可见结果 | 资金及订单处理 |
| --- | --- | --- |
| 休市或午间休息 | 市场状态与最近行情时间 | 不撮合；按本版时段规则允许撤单；不使用收盘价即时成交 |
| 报价超时、缺失或过期 | “行情暂不可用于交易” | 暂停撮合；新委托拒绝；已有委托仍可撤销或到期 |
| 现金或可卖数量不足 | 差额、冻结占用、可卖日期 | 拒单，无资金或持仓变动 |
| 停牌、特殊状态、公司行为待核实 | 具体原因及核对状态 | 暂停受影响证券，保留已成交记录 |
| 浏览器关闭 | 服务运行时委托可继续处理 | 撮合由服务端执行 |
| 服务中断 | 展示停机区间与恢复状态 | 不补造离线成交；恢复后过期订单先到期，同日有效单等待新报价 |
| 重复点击或网络重试 | 返回同一操作结果 | 不重复冻结、扣费、成交或创建账户 |
| 数据恢复或核对失败 | “账户待核对” | 暂停交易，检查通过后恢复 |

## 7. MVP 必须完成与二期边界

首版必需：行情时效、交易规则核对、资金一致性、公司行为检测与阻断、基础恢复及手动交易闭环。即使暂时不提供高级指标，也必须能够对账。
