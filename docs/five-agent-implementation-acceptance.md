# 五 Agent 重构实施与验收

日期：2026-10-04

## 1. 已交付

| 领域 | 实现 |
|---|---|
| 五个角色 | 各自的 system prompt、领域上下文、Zod 工具输入、服务端工具权限和持续会话 |
| 协作 | 总管家按需创建专业子运行；共享事实和调用预算；子运行不混入用户消息，不递归委派 |
| 运行管理 | 消息幂等、会话版本、运行租约、工具步骤、失败恢复、停止、过期资料校验 |
| 确认 | 草稿不修改事实；按钮确认后在短事务内提交预算、保单、持仓、产品意向、红线、目标资料、方案、复盘或行动状态 |
| 查询与计算 | 流水与周期汇总、投入能力、产品版本筛选与比较、通用目标资金检查、历史能力适配 |
| 通用目标 | 草稿、评估历史、方案版本、资金预留和月度实际核对；目标名称不决定计算规则 |
| 五入口 | 资产管家三个顶部页签；收支管家记账和复盘页签；目标管家对话、执行和资金计划；两个专业页面 |
| 兼容 | 原底账、诊断、规划、专项决策、产品库和行动继续使用；旧目标对话可回看，新会话使用新运行层 |
| 数据管理 | 新运行、草稿、决策和快照进入删除传播；恢复数据库后中断旧运行并使旧确认卡失效 |

对话较早内容以带消息编号的原话摘录辅助理解，不能当成已确认的财务事实。金额、来源与权限不由模型解释决定。

## 2. 数据迁移

增量迁移为 `20261004180000_five_agents` 和 `20261004180100_agent_legacy_bridge`。迁移前创建受管理备份，迁移后通过核心财务数据哈希、SQLite 完整性、外键及业务迁移验证。

旧专项决策与方案只增加兼容关联，原始余额、负债、流水、预留、方案及其历史原样保留，不重新生成历史快照。新增关键引用由工作区复合外键和 SQLite 触发器共同约束。

专业页面同时读取新旧资金预留，并展示通用目标的资料缺口、资金影响和月度提醒。

新的 `GoalDecision / GoalEvaluationRecord / GoalPlanVersion / GoalFundingReservation / GoalReview` 承载通用决策；`AgentRun / AgentProposal` 承载运行及待确认操作。它们不建立另一套资产余额。

## 3. 工程验收

新增架构测试覆盖五角色会话、真实工具执行、越权拒绝、专业委派、未确认不落账、过期卡拒绝、幂等、故障恢复、取消后不生成迟到草稿、费用扣除、全局红线、实际余额核对和通用方案采纳。

跨计算流程的测试确认通用目标占用会约束旧方案，旧资料版本变化先拒绝，重新核对后的不足资金不能采纳。

全量回归此前通过 233 项测试（另 1 项迁移专用测试按默认配置跳过；迁移阶段已单独运行）；最后跨模块复核通过 40 项（含 17 项新架构测试，计数与全量回归有重叠）。TypeScript 检查与生产构建通过。ESLint 无错误；复杂度警告保留为后续局部整理项。构建中的本地备份动态文件追踪警告没有阻止构建。

真实模型在独立空白测试空间验证：查询目标后分阶段补问、生成未知字段的资料确认卡、恢复历史对话。自动测试使用注入模型与合成财务资料，避免把真实财务资料作为外部模型测试输入。

## 4. 本期计算能力边界

- 通用能力为一次性目标资金、确认后的月度结余、资产可用日期、费用、其他目标占用、储备底线和恒定持续费用检查，最长十年。不猜测收益、奖金或未来收入增长。
- 目标金额未知时可以保存资料，资金上限可以试算；缺失金额、时间、储备或持续费用时不允许直接采纳。
- 通用方案目前提供一个基础候选和资金缺口；复杂分期、融资、专项费用以及实际执行后的专项维护沿用已验证的既有能力与确认页面。不能支持的请求须说明能力不足，不生成替代的虚构计算。
- 新对话可以提出个人全局红线。既有决策专属红线及其结构化核对继续由原决策能力维护；不把专属约束自动提升为全局约束。
- 新通用方案记录当时确认的约束、偏好证据、预算与持仓假设，理由未表达时保持未知。原有结构化理由、假设和逐次核对表继续保留，未伪造迁移理由或假设成立记录。
- 通用复盘保存真实核对点，提示重算；调整须生成并确认新方案，不静默替换生效版本。
- 旧报告生成与复杂结构化页面保持可用。Agent 解释失败时不影响已确认的数据库操作。
- 不实现自动交易、银行核验、五角色自主互相讨论或多个目标的联合最优分配。

## 5. 查看与复现

本地预览：`http://127.0.0.1:3000`。进入目标管家可直接讨论未知金额的新目标；切换话题或刷新页面后继续。确认卡单独决定是否保存资料。

页面截图见 [五 Agent 预览](five-agent-preview.jpg)。

如模型配置不可用，页面明确说明；底账、计算、筛选及原有确认页面仍可使用。不会把确定性占位回复显示成真实 Agent 回答。

最终展示场景独立放在《五 Agent 场景验收与展示样例》，不作为通用数据模型或工具命名的依据。
