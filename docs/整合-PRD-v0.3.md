# Financial Associates 整合 PRD v0.3

## 定位与范围
完整资产管理产品中的可交互情景推演。五管家、财务底账、目标、评估、规划、行动、保险、投资、模拟交易和数据管理保留；新推演替代旧简易模拟的新建入口。

本机演示，支持人民币买车5年、买房30年；其他目标保留原规划功能，不能伪装为已有通用推演。虚构角色可直接体验；当前底账先转换并由用户确认简化游戏输入。推演结果只保存报告，不修改真实规划和账目。

## 用户流程
1. 在统一产品中查看／录入底账，可切换到独立演示空间。
2. 从未来规划进入情景推演，查看来源资产、纳入金额及排除原因。
3. 确认现金、投资、工资、生活费、租金、既有负债及每月还本金、年度奖金和年龄；缺失信息需补齐。受限资金默认排除，修改只是本局假设。
4. 选择买车或买房，编辑两条付款方案并确认。全款、低首付、高首付任选两种。
5. 逐月计算，按阶段展示；医疗、失业、奖金延期、投资下跌、职业机会沿用v0.2游戏规则。遇到职业选择暂停，支持两条路径分别或同步选择。
6. 保存报告、返回查看；底账更新时提示来源已变。重玩沿用原规则及随机经历。

## 财务口径
剩余资金=现金+投资，负债与购置累计支付分列，车辆和住房不计入剩余资金。既有债务简化为固定月还本金，不模拟原贷款利息；已包含在生活预算中的还款剥离后单列。保费按月等价口径核对，已包含的不重复加入。奖金默认零，确认后每年重复是游戏假设。其他目标未来投入、一次性费用与真实赎回条款未完整模拟，确认页明确说明。

当前底账游戏从确认时点的下一个完整自然月结算；游戏开局完成购置。受限、不可用、固定或未识别资产默认排除，不虚构可用日期。所有纳入的投资在游戏里按即时变现、无手续费规则处理。

## 演示与资料边界
演示工作区、财务底账、保单及20日行情均明确标记为构造数据。重新演示创建新工作区，不覆盖原数据。手动回放与AI策略账户各自独立，不修改真实行情核验规则；AI策略必须经用户确认与授权，程序负责最终风控和撮合。

AI负责读取已确认信息、方案整理、事实解释与引擎验证后的建议；不能决定事件、确认方案或改写账目。模型或搜索失败明确显示规则回退。单次随机结果不代表普遍结论或个人财务建议。
