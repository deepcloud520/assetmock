# 首页视觉资源

- 标题数字使用 [Instrument Serif](https://github.com/google/fonts/tree/main/ofl/instrumentserif)，从 Google Fonts 官方仓库下载并在应用内托管。字体遵循 [SIL Open Font License 1.1](../src/app/fonts/OFL-InstrumentSerif.txt)。`InstrumentSerif-Regular.ttf` 的 SHA-256 为 `498efd461f6ddfcb7a111bf9a565709d2085d48201d501ead960d93e84ffbb88`。
- 界面图标继续使用项目已有的 [Lucide](https://lucide.dev/)，遵循 [ISC 许可](https://github.com/lucide-icons/lucide/blob/main/LICENSE)。
- 明亮蓝、浅蓝与冷白由项目样式变量定义。配色层级参考 [Radix Colors 的调色方法](https://www.radix-ui.com/colors/docs/palette-composition/composing-a-palette)，没有导入外部样式表。

以上资源随应用本地提供，页面运行时无需请求第三方字体、图片或脚本服务。
